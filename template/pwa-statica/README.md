# __NOME__

__DESCRIZIONE__ Con **__MASCOTTE__**, la mascotte (__ANIMALE__).

👉 **https://marketto.github.io/__ID__/**

- Installabile come app, funziona offline e si aggiorna da sola.
- Nessun account e nessun server: i dati restano sul tuo dispositivo.
- In 42 lingue, con temi chiaro, scuro, alto contrasto e per daltonici.

## Sviluppo
```bash
npm install         # una volta (strumenti di sviluppo)
npm test            # logica, lingue, testi legali, privacy
npm run check       # 42 lingue, legali adattati, interfaccia in tutti i temi e larghezze
npm run serve       # http://localhost:8000
npm run icons       # icone dalla mascotte (js/mascot.js)
npm run font        # font di icone (tools/icons/icons.mjs)
```
Guida per agenti: `AGENTS.md` (Claude, Codex, Cursor, Copilot, Gemini). Nato da [app-forge](https://github.com/Marketto/app-forge).
